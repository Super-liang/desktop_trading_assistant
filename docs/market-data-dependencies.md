# 行情与交易日历依赖基线

0.1.6 固定使用以下版本，升级前必须通过网关列名、代码、时区和节假日契约测试：

| 依赖 | 固定版本 | 许可证 | 用途与限制 |
| --- | --- | --- | --- |
| AKShare | 1.18.72 | MIT | 公开网站行情适配；不承诺交易所级实时 SLA |
| exchange-calendars | 4.13.2 | Apache-2.0 | XSHG、XHKG、XNYS 会话、午休、DST 与提前收市 |

数据能力约束：

- A 股指数使用东方财富沪深京指数快照，新浪中国股票指数作为通过契约测试后的降级来源。
- 港股东方财富行情约有 15 分钟延迟，界面必须展示来源、行情时间和延迟提示。
- 美股只处理常规交易时段；新浪降级行情按约 15 分钟延迟展示，不宣传盘前/盘后实时行情。
- 公募基金首期仅处理开放式基金单位净值；净值按 Provider 披露日期落库，不把自然日当作净值日。
- 上游失败时保留最后成功行情并标记过期，不清空 Redis 业务数据。

依赖升级步骤：在隔离环境安装候选版本，运行 Python 全量测试和真实非生产接口探测，确认列名、指数代码、交易日及提前收市样例后再修改固定版本。
