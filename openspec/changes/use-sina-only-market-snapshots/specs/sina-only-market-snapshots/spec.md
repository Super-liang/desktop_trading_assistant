## ADDED Requirements

### Requirement: 全市场快照仅使用新浪来源
系统 MUST 仅通过新浪来源刷新 A 股、港股全市场快照和美股持仓/自选证券行情，不得在行情调度中请求东方财富全市场来源。

#### Scenario: A 股交易时段刷新
- **WHEN** A 股市场处于交易中且达到管理员配置的刷新间隔
- **THEN** 系统仅请求并更新 A 股新浪全市场快照

#### Scenario: 港股交易时段刷新
- **WHEN** 港股市场处于交易中且达到管理员配置的刷新间隔
- **THEN** 系统仅请求并更新港股新浪全市场快照

#### Scenario: 美股交易时段按持仓刷新
- **WHEN** 美股市场处于交易中、达到管理员配置的刷新间隔且系统存在美股持仓或自选证券
- **THEN** 系统去重证券标识后批量请求新浪行情，并只更新成功返回的美股 Redis 字段

#### Scenario: 无美股证券时不调用上游
- **WHEN** 美股市场处于交易中但系统不存在美股持仓或自选证券
- **THEN** 系统不得调用新浪美股行情接口

#### Scenario: 非交易时段停止刷新
- **WHEN** 某市场未处于交易中
- **THEN** 系统不得请求该市场全市场快照，并继续保留最后一次成功数据

### Requirement: 港股新浪行情契约
AKShare 网关 MUST 支持新浪港股全市场接口，并将结果标准化为系统现有的港股行情契约。

#### Scenario: 港股行情成功标准化
- **WHEN** 新浪港股接口返回包含代码、名称、最新价、今开和昨收的有效数据
- **THEN** 网关返回以 `HKEX:<五位代码>` 标识且来源为新浪的标准行情列表

#### Scenario: 港股字段异常
- **WHEN** 新浪港股接口缺少必需字段或返回不可解析数据
- **THEN** 网关将本次请求标记为失败且不得用异常结果覆盖最后成功快照

### Requirement: 美股持仓新浪批量行情契约
网关 MUST 仅接受规范化的美股证券标识，并通过新浪批量行情接口返回标准 Quote，且不得接收或记录用户身份、数量和成本。

#### Scenario: 批量查询成功
- **WHEN** 服务端提交去重后的 `NASDAQ/NYSE/AMEX:<symbol>` 列表且新浪返回有效行情
- **THEN** 网关返回对应证券的价格、昨收、开高低、涨跌、成交量和来源时间

#### Scenario: 非法美股标识
- **WHEN** 请求包含非美股交易所、非法代码或超过单轮上限的列表
- **THEN** 网关拒绝请求且不得调用新浪上游

#### Scenario: 部分证券无行情
- **WHEN** 新浪只返回请求列表中的部分证券
- **THEN** 系统仅更新已成功返回证券，并保留其他证券最后成功数据

### Requirement: 旧全市场来源配置兼容
系统 MUST 将历史保存或旧客户端提交的东方财富全市场来源自动归一化为新浪，同时保持单股模式来源配置不变。

#### Scenario: 读取历史管理员配置
- **WHEN** 数据库中的全市场来源仍为 `EASTMONEY`
- **THEN** API 对外返回 `SINA` 并按新浪线路调度行情

#### Scenario: 旧客户端提交东方财富
- **WHEN** 旧客户端在全市场模式请求中提交 `EASTMONEY`
- **THEN** 服务端按 `SINA` 处理该请求且不得访问东财全市场接口

#### Scenario: 单股来源不受影响
- **WHEN** 用户选择单股行情模式及其既有来源
- **THEN** 系统保持既有单股来源选择和轮询行为

### Requirement: 新浪快照永久保留最后成功数据
系统 MUST 将每个市场的新浪行情分别保存在 Redis 中，不设置主动失效时间；A 股和港股仅在完整刷新成功时更新，美股仅更新成功返回的持仓/自选证券。

#### Scenario: 完整刷新成功
- **WHEN** 某市场新浪全市场数据完整获取并通过契约校验
- **THEN** 系统原子更新该市场新浪快照、数量和最后成功时间，且快照键无 TTL

#### Scenario: 刷新失败
- **WHEN** 新浪接口超时、断开或返回无效数据
- **THEN** 系统保留该市场最后一次成功快照及其最后成功时间

### Requirement: 行情消费者统一读取新浪快照
系统 MUST 使持仓行情、收益计算和开盘基线按证券所属市场读取新浪全市场快照。

#### Scenario: 跨市场持仓查询
- **WHEN** 用户持有 A 股、港股或美股证券并查询持仓
- **THEN** 系统分别从对应市场的新浪快照返回行情，不得过滤非 A 股证券

#### Scenario: 开盘基线采集
- **WHEN** 某市场第一份有效新浪快照刷新成功
- **THEN** 系统基于该新浪快照采集当日持仓开盘基线

### Requirement: 页面仅展示新浪全市场来源
Web 和桌面客户端 MUST 在全市场模式中只展示新浪来源，并且联通检测不得展示东财全市场线路。

#### Scenario: 用户查看全市场配置
- **WHEN** 普通用户或管理员打开全市场行情配置
- **THEN** 页面显示固定来源为新浪且不存在东方财富全市场选项

#### Scenario: 管理员配置刷新频率
- **WHEN** 管理员修改服务端全市场刷新秒数
- **THEN** 系统保存刷新频率但全市场来源仍固定为新浪

#### Scenario: 客户端迁移旧偏好
- **WHEN** 客户端本地保存的全市场来源为 `EASTMONEY`
- **THEN** 客户端自动改用并持久化 `SINA`
