## ADDED Requirements

### Requirement: 管理员按用户查看最后登录信息
系统 SHALL 允许管理员搜索用户并查看其最后一次密码登录时间；从未进行密码登录时 SHALL 显示明确的空状态。

#### Scenario: 用户已登录过
- **WHEN** 管理员查看一个有登录记录的用户
- **THEN** 列表和用户详情显示该用户最近一次成功密码登录的时间

#### Scenario: 用户从未密码登录
- **WHEN** `last_login_at` 为空
- **THEN** 管理界面显示“尚未登录”而不是错误日期

### Requirement: 管理员查看隐私化用户概况
系统 MUST 通过按用户的专用管理接口返回持仓证券清单和聚合收益，不得返回数量、成本、总市值或单只证券收益金额。

#### Scenario: 查看用户详情
- **WHEN** 管理员打开指定用户详情
- **THEN** 系统返回证券代码、名称、市场、行情状态以及用户级日收益、本年收益和年化收益率摘要

#### Scenario: 普通用户调用管理接口
- **WHEN** 非管理员请求任一用户管理详情接口
- **THEN** 系统拒绝访问且不泄露目标用户是否存在或持仓信息

### Requirement: 关键用户操作被安全审计
系统 MUST 记录持仓新增、修改、删除和密码修改操作的动作、主体、目标、结果和发生时间，但不得记录数量、成本、密码、令牌或完整请求/响应正文。

#### Scenario: 新增或删除持仓成功
- **WHEN** 用户成功新增、修改或删除持仓
- **THEN** 系统写入对应不可变审计记录，包含用户、动作、证券标识和时间

#### Scenario: 修改密码
- **WHEN** 用户发起密码修改且操作成功或失败
- **THEN** 系统记录结果但审计内容中不包含任何密码值或哈希

### Requirement: 管理员按用户筛选审计日志
系统 SHALL 提供强制绑定目标用户的分页审计查询，并支持按动作和时间范围筛选，结果按发生时间倒序。

#### Scenario: 查询指定用户
- **WHEN** 管理员请求某一用户的审计列表
- **THEN** 响应只包含该用户的审计，不混入其他用户记录

#### Scenario: 使用筛选条件
- **WHEN** 管理员指定动作或起止时间
- **THEN** 系统只返回同时满足用户与筛选条件的分页结果
