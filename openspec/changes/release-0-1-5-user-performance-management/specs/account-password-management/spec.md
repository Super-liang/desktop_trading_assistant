## ADDED Requirements

### Requirement: 登录用户可修改密码
系统 SHALL 允许已登录用户提交当前密码、新密码和确认密码来修改自己的密码，并 MUST 校验当前密码正确、新密码符合现有强度策略、确认值一致且新旧密码不同。

#### Scenario: 修改成功
- **WHEN** 用户提交正确当前密码及合法且一致的新密码
- **THEN** 系统保存新的密码哈希，不保存明文密码，并返回成功结果

#### Scenario: 当前密码错误
- **WHEN** 用户提交错误的当前密码
- **THEN** 系统拒绝修改并返回不暴露账户内部信息的错误提示

#### Scenario: 新密码不符合规则
- **WHEN** 新密码强度不足、与旧密码相同或两次输入不一致
- **THEN** 系统拒绝修改并指出可修正的校验原因

### Requirement: 改密后撤销刷新会话
系统 MUST 在密码修改成功后撤销该用户全部刷新令牌，客户端 MUST 清除本地会话并要求重新登录。

#### Scenario: 旧刷新令牌继续使用
- **WHEN** 密码修改成功后任一旧刷新令牌被提交
- **THEN** 系统拒绝签发新的访问令牌

#### Scenario: 客户端收到改密成功
- **WHEN** 客户端收到修改密码成功响应
- **THEN** 客户端删除本地认证信息并返回登录页面
