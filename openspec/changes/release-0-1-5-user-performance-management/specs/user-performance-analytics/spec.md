## ADDED Requirements

### Requirement: 当前用户可查看参考收益摘要
系统 SHALL 为已登录用户提供日收益金额、日收益率、本年收益金额、本年收益率、年化收益率、统计起始日、计算时间和数据状态；收益无法完整计算时 MUST 返回明确状态，不得以零值替代未知值。

#### Scenario: 盘中行情完整
- **WHEN** 用户持仓的现价、昨收和数量均可用
- **THEN** 系统按当前持仓相对昨收计算日收益金额及日收益率，并返回最新计算时间

#### Scenario: 行情或基数缺失
- **WHEN** 部分持仓没有有效行情或收益率分母为零
- **THEN** 系统返回 `PARTIAL` 或 `UNAVAILABLE` 状态及缺失信息，客户端展示参考状态而非伪造零收益

### Requirement: 每日收益被幂等固化
系统 MUST 在有效 A 股交易日收盘后按用户和交易日幂等保存收益聚合，并使用统一的服务端结算行情源。

#### Scenario: 同一交易日任务重试
- **WHEN** 日终结算任务对同一用户和交易日重复执行
- **THEN** 系统更新同一条聚合记录且不创建重复记录

#### Scenario: 非交易日
- **WHEN** 当前日期不在 A 股交易日历中
- **THEN** 系统不生成伪造的每日收益记录

### Requirement: 年度与年化口径透明
系统 SHALL 从功能上线后的首个有效收益日累计本年收益和时间加权本年收益率；年化收益率只有在至少积累 30 个有效自然日后才能展示。

#### Scenario: 统计时间不足
- **WHEN** 用户的有效统计跨度少于 30 个自然日
- **THEN** 年化收益率状态为 `ACCUMULATING`，界面展示“数据积累中”及统计起始日

#### Scenario: 跨年
- **WHEN** 进入新的自然年度
- **THEN** 本年累计口径从该年度首个有效交易日重新开始，而历史每日记录继续保留

### Requirement: 收益数据标明参考性质
系统 MUST 将未包含成交、现金流、费用、税费、分红和复权影响的收益标识为参考/估算数据。

#### Scenario: 用户查看收益说明
- **WHEN** 用户查看首页收益指标或其说明
- **THEN** 客户端明确提示当前收益为基于手工持仓和行情计算的参考值
