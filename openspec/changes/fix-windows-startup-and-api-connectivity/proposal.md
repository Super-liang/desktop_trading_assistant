## Why

Windows 0.1.3 安装版在未登录时提前显示空白透明浮窗，并且登录请求无法连接线上 API，导致用户无法正常进入应用。需要修复 Windows 打包运行时的窗口生命周期和 API 地址解析，恢复与 macOS、本地开发环境一致的登录体验。

## What Changes

- 透明浮窗默认不在应用启动或登录页阶段展示，仅在用户登录成功后按产品规则展示。
- 退出登录或登录状态失效时隐藏透明浮窗，避免未认证状态残留空窗口。
- 修复 Windows 安装包内 API 基础地址的构建与运行时解析，确保登录请求指向已部署后端。
- 为 API 地址选择和浮窗认证状态增加可验证的自动化测试或构建检查。
- 验证 Windows 生产构建配置，不改动管理员、行情源或用户数据协议。

## Capabilities

### New Capabilities

- `windows-runtime-reliability`: 定义 Windows 桌面安装版在认证前后的浮窗可见性，以及生产 API 连接行为。

### Modified Capabilities

无。

## Impact

- 影响桌面端窗口初始化、登录状态同步、退出登录处理及前端 API 客户端配置。
- 可能影响 Tauri Windows 权限配置、生产环境变量注入或构建脚本。
- 不修改服务端公开 API、数据库结构、行情刷新机制和现有用户数据。
