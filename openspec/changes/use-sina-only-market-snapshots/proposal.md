## Why

东方财富公开行情接口在腾讯云服务器上持续出现远端主动断开和请求超时，导致 A 股、港股等全市场快照长期不可用。为提高一期行情服务的可用性，需要将全市场快照统一切换到当前已验证可连通的新浪源，并停止后台继续请求东方财富线路。

## What Changes

- **BREAKING**：全市场快照模式移除东方财富来源，不再允许管理员或普通用户选择东方财富全市场源。
- A 股、港股全市场快照仅调度新浪来源；美股改为仅按系统内用户持仓/自选证券集合批量查询新浪行情。
- AKShare 网关补充港股新浪全市场快照适配，并统一输出既有跨市场行情契约。
- 后端配置读取时将历史东方财富选择自动归一化为新浪，避免旧数据库配置导致服务无法刷新。
- 前端行情配置和用户偏好中移除全市场东方财富选项；单股模式既有来源不受本次变更影响。
- 联通检测和来源能力列表不再把东方财富全市场线路显示为可用能力。

## Capabilities

### New Capabilities

- `sina-only-market-snapshots`: 规定 A 股、港股全市场快照仅使用新浪源，美股按持仓/自选证券批量刷新，并覆盖旧配置迁移、刷新时段、缓存保留和来源展示行为。

### Modified Capabilities

无。当前 `openspec/specs/` 尚无已归档的全市场行情来源规范；本变更以独立能力承接该约束。

## Impact

- AKShare 网关：港股新浪数据装载、字段归一化、能力声明及契约测试。
- Java API：快照调度路由、配置归一化、来源状态和 Redis 读取策略。
- 桌面/Web 前端：行情来源设置、用户本地偏好及联通检测文案。
- 数据兼容：保留现有枚举和历史 Redis 键的读取兼容，但停止产生新的东方财富全市场快照。
- 不影响单股行情模式、公募基金净值以及证券目录同步来源。
