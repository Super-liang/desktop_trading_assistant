# 产品需求、竞品与合规说明

## 定位

项目不复刻重型交易终端，而是做“Win/Mac 原生可信、极简隐蔽、行情多源可追溯、持仓隐私优先”的个人桌面盯盘层。深度行情或交易可跳转专业终端。

## 市场优势与痛点

| 产品类别 | 可吸收优势 | 主要痛点 / 本项目机会 |
| --- | --- | --- |
| 同花顺、东方财富 | 全市场覆盖、深度指标、账号同步、Level-2 付费分层 | 功能重、信息密度高；单一中心源异常时影响范围大 |
| 腾讯自选股 | 极简、自选同步、低学习成本、价格提醒 | 透明原生小窗、老板键、持仓成本/盈亏不是核心卖点 |
| 雪球/雪盈 | 自定义看板、事件资讯、跨端同步 | 社区噪声与治理成本高，消费产品数据禁止未授权抓取 |
| 幽灵看盘、看盘神器等 | 透明度、悬浮、快捷隐藏直接命中办公场景 | 常见仅 Windows、个人维护、未签名、单接口失效、热键或内存问题 |

## 一期验收

1. Windows 10/11 与 macOS 13+ 可构建；发行前完成签名、公证与双平台真机验收。
2. 管理主窗和透明盯盘小窗独立；小窗无边框、置顶、可拖动。
3. 全局老板键一次隐藏所有盯盘窗，再次操作安全恢复；托盘可显示、隐藏和退出。
4. 用户可注册、登录、刷新/退出、注销；管理员可分页搜索、启停用户并查询审计。
5. 用户可搜索 A 股代码并手工录入数量/成本；系统用 Decimal 计算市值、浮盈亏和收益率。
6. 行情显示 Provider、行情时间、市场阶段、DEMO/延迟/陈旧状态；断流不得伪装实时。
7. Provider SPI 支持多源优先级和健康降级；无授权源时只能运行明确 DEMO 数据。

## 二期

- 主题、红涨绿跌/反色、字体密度、透明度、热键、刷新频率、窗口布局、多自选组。
- 价格/成本线/止盈止损参考线、涨跌幅和异动提醒、免打扰。
- 套餐、权益、订单、续费/退款、会员筛选和权益审计；基础安全、注销、行情时间戳不能收费。
- 数据源运营台：授权期限、优先级、配额、延迟、错误率、切源记录和质量对账。
- “仅本机加密持仓”和显式同意的云同步。

## 三期

先做有依据的解释型诊股：基本面/技术面/公告摘要、风险因子和情景分析，每项结论显示数据来源、时间、模型版本与不确定性并留审计。未经持牌合作不得上线买卖时机、个股推荐、收益承诺或收费荐股。

证监会明确，利用软件提供具体证券分析意见、价格预测或买卖时机并获利，属于证券投资咨询业务：[关于“荐股软件”的监管答复](https://www.csrc.gov.cn/csrc/c100028/c1002326/content.shtml)。

## 用户隐私

持仓数量、成本和盈亏可反映个人财产状况。系统坚持最小必要、用户隔离、传输加密、备份加密、日志脱敏、管理员默认不可见明细，并提供注销删除路径。上线主体需准备隐私政策、用户协议、数据导出/删除，并评估 ICP 与应用备案。
