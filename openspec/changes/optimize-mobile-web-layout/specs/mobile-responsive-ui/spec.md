## ADDED Requirements

### Requirement: 手机端主导航保持单行可触控
系统 SHALL 在宽度 320px 至 900px 的网页版视口中提供单行底部主导航，主入口不得换行，低频账号操作 SHALL 收纳到可展开的更多操作区域。

#### Scenario: 普通用户在窄屏查看主导航
- **WHEN** 普通用户在 375px 宽的手机浏览器登录
- **THEN** 系统以单行展示首页、我的持仓、实时行情源和更多四个入口
- **AND** 修改密码与退出登录可从更多区域访问

#### Scenario: 管理员访问管理入口
- **WHEN** 管理员在手机端打开更多区域
- **THEN** 系统展示用户管理入口以及账号操作

### Requirement: 固定区域不得遮挡业务内容
系统 SHALL 为底部导航和设备安全区预留一致的内容空间，页面末尾操作、提示和弹窗不得被固定导航遮挡。

#### Scenario: 页面滚动到底部
- **WHEN** 用户在任一关键业务页面滚动到最底部
- **THEN** 最后一项内容完整显示在底部导航上方

#### Scenario: 手机端打开表单弹窗
- **WHEN** 用户在手机端打开添加持仓、编辑持仓或修改密码弹窗
- **THEN** 遮罩覆盖底部导航
- **AND** 弹窗可在动态视口高度内滚动到全部字段与提交按钮

### Requirement: 关键页面适配常见手机尺寸
系统 SHALL 在 390×844 与 375×667 视口下保持登录页、首页、持仓页、行情源页及持仓弹窗可读且无页面级横向溢出。

#### Scenario: 首页在手机视口展示
- **WHEN** 用户在手机视口打开首页
- **THEN** 行情来源说明可换行且不截断页面
- **AND** 指数卡片可横向滑动
- **AND** 收益与操作卡片按单列或紧凑网格展示

#### Scenario: 持仓页在手机视口展示
- **WHEN** 用户打开包含持仓的市场页
- **THEN** 市场标签可横向滑动并完整选择所有市场
- **AND** 每个持仓卡片不因桌面填充布局产生与内容无关的大块空白
- **AND** 编辑和删除按钮保持至少 44px 的触控区域

#### Scenario: 行情源页在短屏展示
- **WHEN** 用户在 375×667 视口打开实时行情源页面
- **THEN** 状态卡片、模式选择和保存操作可通过纵向滚动完整访问
- **AND** 保存操作不被底部导航遮挡

### Requirement: 桌面端布局保持兼容
系统 MUST 将移动端优化限制在响应式断点内，不得改变大于 900px 视口的桌面侧边栏、列表密度和弹窗宽度行为。

#### Scenario: 桌面视口回归
- **WHEN** 网页或桌面壳视口宽度大于 900px
- **THEN** 系统继续展示桌面侧边栏
- **AND** 不展示移动端底部导航或更多操作区域
