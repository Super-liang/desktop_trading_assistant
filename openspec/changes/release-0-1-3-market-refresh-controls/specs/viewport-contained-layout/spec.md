## ADDED Requirements

### Requirement: 主页面受当前窗口可视区约束
桌面端主窗口的工作台、行情配置页和用户管理页 MUST 将页面外框限制在当前窗口高度内，MUST NOT 产生整个文档的纵向滚动条。

#### Scenario: 默认 1180×760 窗口打开工作台
- **WHEN** 用户在默认主窗口尺寸打开盯盘工作台
- **THEN** 侧栏、页头、行情状态、摘要和自选卡片均位于当前窗口内，窗口级页面无需上下滚动

#### Scenario: 默认窗口打开行情配置页
- **WHEN** 用户在默认主窗口尺寸进入实时行情源配置
- **THEN** 返回按钮、模式选择、来源设置和保存按钮均位于当前窗口可视区内

### Requirement: 长数据使用卡片内部滚动
当自选、持仓、用户或审计记录超过可视高度时，系统 MUST 仅在对应内容卡片内部提供纵向滚动，并 MUST 保持页面导航和主要操作位于当前窗口内。

#### Scenario: 自选标的超过一屏
- **WHEN** 自选与持仓行数超过列表卡片剩余高度
- **THEN** 行情表区域内部可滚动，主窗口文档和侧栏不随列表滚动

#### Scenario: 管理后台记录超过一屏
- **WHEN** 用户或审计记录超过管理页可用高度
- **THEN** 记录区内部可滚动，管理页页头与返回操作保持可见

### Requirement: 较矮窗口保持操作可达
在应用允许的最小窗口高度下，系统 MUST 使用紧凑间距和弹性区域保持主要操作可见，不得依赖整页纵向滚动访问保存、返回或添加操作。

#### Scenario: 主窗口缩放到最小允许高度
- **WHEN** 用户将主窗口缩放到配置允许的最小高度
- **THEN** 当前页面的主要导航和提交操作仍可见，内容列表在局部区域内滚动
