# 产品更名与透明小窗切换设计

## 目标

- 当前产品界面、Tauri 发布元数据、托盘提示、README 和交付报告统一改为“股票盯盘助手”。
- 历史 OpenSpec 记录保留原文。
- 主界面“透明小窗”按钮能够显示和隐藏 ticker。

## 技术设计

更名采用精确范围替换，不修改应用 identifier，因此已有本机应用数据继续复用。Tauri `productName` 更新后，新构建的 `.app` 和 DMG 文件名同步变化。

按钮点击不保存 React 本地可见状态，而是每次调用 ticker 的 `isVisible()`。窗口可见时调用 `hide()`；窗口隐藏时先广播当前会话，再调用 `show()` 和 `setFocus()`。这样即使小窗通过自身按钮、老板键或托盘改变状态，下一次点击也不会失真。

## 验证

- Vitest mock Tauri 窗口与事件模块，覆盖可见时隐藏、隐藏时同步并显示、外部隐藏后重显。
- 扫描当前界面与交付文件，确认不再出现“股票定盘助手”。
- 执行完整前端测试、生产构建、Rust 检查、OpenSpec 严格校验和 macOS 发布构建。

## 非目标

- 不修改历史 OpenSpec 记录。
- 不增加 Rust IPC 或数据库迁移。
- 不改变透明、响应式、老板键和会话模型。
