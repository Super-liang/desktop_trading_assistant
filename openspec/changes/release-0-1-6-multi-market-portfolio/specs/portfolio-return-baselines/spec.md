## ADDED Requirements

### Requirement: 股票日收益使用开盘持仓基线
系统 SHALL 为每个股票市场交易日保存持仓的开盘数量、有效开盘价、币种、来源和采集时间，并 SHALL 按 `开盘数量 × (当前价 - 开盘价)` 计算日收益。

#### Scenario: 正常建立开盘基线
- **WHEN** 市场开盘后首次获得包含有效今开的行情
- **THEN** 系统幂等保存该交易日开盘数量和开盘价并计算日收益

#### Scenario: 午间休市读取收益
- **WHEN** A 股或港股进入午间休市
- **THEN** 系统基于已保存开盘基线和最后行情继续展示日收益，不创建第二份基线

#### Scenario: 开盘价缺失
- **WHEN** 某持仓当日行情没有有效开盘价
- **THEN** 该持仓日收益状态为不可用且聚合状态为部分或不可用，不以昨收或成本静默替代

### Requirement: 当日新增或编辑持仓不伪造日收益
系统 SHALL 在股票市场开盘后新增持仓，或修改数量、成本、建仓日期时，将该持仓当日标准日收益标记为不可用，并从下一交易日重新建立基线。

#### Scenario: 盘中新增持仓
- **WHEN** 用户在市场开盘后新增股票持仓
- **THEN** 页面仍可显示持有收益，但当日日收益显示“下一交易日起统计”

#### Scenario: 盘中修改数量
- **WHEN** 用户在已建立基线后修改持仓数量
- **THEN** 系统不把新数量套用旧开盘价计算当日收益

### Requirement: 持有收益只基于成本和当前价格
系统 SHALL 按 `当前数量 × (当前价 - 成本价)` 计算持有收益，并 SHALL 按 `(当前价 - 成本价) / 成本价` 计算持有收益率。

#### Scenario: 股票持有收益
- **WHEN** 股票持仓具有有效成本和当前行情
- **THEN** API 返回原币种持有收益及持有收益率

#### Scenario: 成本缺失或为零
- **WHEN** 持仓没有有效正成本
- **THEN** 持有收益和收益率为不可用，不发生除零或伪造零收益

### Requirement: 基金收益使用相邻净值
系统 SHALL 按基金份额乘以最新净值与前一净值之差计算净值日收益，并按最新净值与成本净值计算持有收益。

#### Scenario: 基金相邻净值齐全
- **WHEN** 最新净值和前一净值日期、数值均有效
- **THEN** 系统返回净值日收益、净值日收益率、持有收益和净值日期

#### Scenario: 建仓日期不早于最新净值日期
- **WHEN** 基金建仓日期等于或晚于最新净值日期
- **THEN** 净值日收益为不可用，持有收益可在成本和最新净值有效时展示

### Requirement: 收益聚合必须按市场和币种分组
系统 MUST NOT 将 CNY、HKD 和 USD 金额直接相加，并 SHALL 为每个市场/币种返回独立的日收益、持有收益和数据状态。

#### Scenario: 用户同时持有三种币种
- **WHEN** 用户拥有 A 股、港股和美股持仓
- **THEN** 首页展示 CNY、HKD、USD 三组收益，不展示无汇率依据的总金额

### Requirement: 年度和年化收益退出产品展示
0.1.6 桌面端 MUST 删除年度收益、年度收益率和年化收益率展示，新收益 API SHALL 不包含这些指标。

#### Scenario: 旧客户端过渡
- **WHEN** 0.1.5 客户端调用旧 performance 接口
- **THEN** 后端可返回年度/年化字段为 `null` 并标记弃用，但不继续计算误导性指标
