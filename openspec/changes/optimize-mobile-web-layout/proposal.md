## Why

当前网页版在 390px 及更窄的手机视口下存在底部导航换成两行、内容被遮挡、持仓区域出现大块空白、横向标签被截断及弹窗在矮屏上接近溢出等问题，影响查看行情和维护持仓的核心流程。需要建立明确的移动端布局约束，让主要页面在常见手机尺寸下保持可读、可触控、无非预期横向溢出。

## What Changes

- 将手机端底部导航改为稳定的单行主导航，把低频操作收纳到“更多”入口，避免两行导航占用内容空间。
- 为固定底部导航统一预留安全区和内容间距，避免页面内容、按钮或弹窗被遮挡。
- 优化首页行情来源标签、指数轮播、收益卡片及操作区在窄屏下的换行和密度。
- 优化持仓市场标签与持仓卡片的移动端排版，移除不必要的固定高度和大块空白。
- 优化添加/编辑持仓、行情源配置和账号操作弹窗在短屏手机上的最大高度、内部滚动与触控尺寸。
- 补充 390×844 与 375×667 两类手机视口的响应式回归验证，并保持桌面端既有布局不变。

## Capabilities

### New Capabilities

- `mobile-responsive-ui`: 定义网页版关键业务页面在手机宽度和短屏场景下的导航、布局、弹窗、触控与溢出要求。

### Modified Capabilities

无。

## Impact

- 主要影响 `apps/desktop` 的 React 页面组件、导航组件和响应式样式。
- 不修改后端 API、数据库结构、行情同步策略或桌面透明浮窗协议。
- 网页版与桌面壳共用前端资源，因此媒体查询必须限定在移动端断点，避免影响 Windows/macOS 桌面窗口。
