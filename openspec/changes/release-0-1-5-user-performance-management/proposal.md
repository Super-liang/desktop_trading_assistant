## Why

0.1.5 需要把当前以“行情 + 持仓表”为中心的单页应用升级为更清晰的个人投资看板，并补齐管理员按用户查看运营信息、用户安全自助和关键操作追溯能力。与此同时，单股行情在上游短时失败时会丢失显示、移动浏览器无法完整操作，这些问题会直接影响 ToC 产品的可靠性与可用性。

## What Changes

- 管理员用户管理增加最后一次密码登录时间、按用户查询的隐私化持仓概况、收益摘要和关键操作审计；管理员接口不得返回持仓数量、成本或可直接反推出单只仓位规模的字段。
- 新增普通用户关键操作审计，记录持仓新增、修改、删除和密码修改等结果，但不记录数量、成本、密码、令牌或完整请求内容。
- 首页移除持仓表，新增“我的持仓”独立页面；首页新增日收益、本年收益和年化收益率摘要，并支持金额/比率切换。新增持仓成功后跳转到“我的持仓”。
- 明确收益口径：盘中日收益按当前持仓相对昨收估算；本年收益基于上线后形成的每日收益快照累计；年化收益率在至少积累 30 个有效自然日后展示，数据不足时显示“数据积累中”。不提供非标准的“年化收益金额”，金额维度展示“本年收益”。
- 登录用户可校验原密码后修改密码；成功后撤销现有刷新令牌并要求重新登录。
- 单股行情按来源写入 Redis 永久缓存；刷新成功只覆盖最新值，上游失败时继续返回最后一次成功行情并标记陈旧，仅在从未取得过数据时显示无可用行情。
- 增加手机浏览器响应式导航、可滚动页面、卡片化数据展示、适配对话框和触控尺寸；不改变桌面透明小窗的行为。
- 使用 `assets/branding/yinxian-app-icon-v1.png` 重新生成 macOS、Windows 和 Web 图标资源。

## Capabilities

### New Capabilities

- `user-performance-analytics`: 定义个人日收益、本年收益、年化收益率、每日快照、数据状态和隐私口径。
- `admin-user-insights-audit`: 定义管理员按用户查看最后登录、隐私化收益/持仓概况与关键操作审计的能力。
- `account-password-management`: 定义登录用户修改密码、密码策略、会话撤销及审计行为。
- `portfolio-page-and-responsive-ui`: 定义首页与“我的持仓”页面分离、新增后跳转、收益展示切换及移动端适配。
- `resilient-single-stock-quotes`: 定义单股行情按来源永久保留最后成功数据和失败降级行为。
- `application-branding`: 定义桌面安装包与浏览器使用统一的新应用图标。

### Modified Capabilities

- 无；当前 `openspec/specs/` 尚无已归档的对应基线能力，本变更以新增规范建立事实来源。

## Impact

- 后端：用户、认证、持仓、管理员、行情网关与 Redis 缓存模块；新增数据库迁移、收益计算/结算服务、普通用户审计与管理端聚合接口。
- 前端：拆分 `Dashboard` 页面职责，新增首页、我的持仓、管理员用户详情、修改密码和移动导航；扩展 API DTO 与查询缓存策略。
- 数据：新增用户操作审计与每日收益聚合数据；敏感持仓原始字段仅供本人接口和服务端计算使用。
- 运维：Redis 需要持久化单股最后行情；每日结算使用 `Asia/Shanghai` 时区并保证幂等，历史数据不做虚假回补。
- 发布：重新生成 Tauri 全平台图标和 Web favicon，并对 macOS、Windows、桌面尺寸及典型手机尺寸执行验证。
